# CE-MRI-synthesis

本项目基于条件生成对抗网络（cGAN），使用 RegNet 作为骨干网络，实现从多序列平扫 MRI 图像生成对比增强 MRI（CE-MRI）图像。

> 本项目基于 PyTorch Lightning 框架开发

## 快速开始

### 1. 数据预处理

请按照以下工作流程进行数据预处理：

**步骤 1：生成身体掩码**
```bash
python resemble_n_get_body/get_body_t1.py
```
> 用于生成 T1 序列（或其他指定序列）的身体掩码
> 注意:从 MRI 图像中分割出人体轮廓/身体区域，去除背景、扫描床、体外空气等非人体部分，为后续处理提供统一的掩码范围生成身体掩码（Body Mask），而不是 ROI（感兴趣区域）掩码。
> 实现流程:
> ```plaintext
> 原始 T1 图像 → 阈值分割 → 孔洞填充 → 形态学操作 → 最大连通域提取 → 身体掩码
> ```

**步骤 2：应用掩码到所有序列**
```bash
python resemble_n_get_body/get_body_all_series.py
```

**步骤 3：T1 重采样**
```bash
python reg_series/resample_t1.py
```
> 将所有 T1 图像重采样到选定的参考 T1，确保尺寸和间距一致

**步骤 4：所有序列重采样到 T1**
```bash
python reg_series/itk_resample_all2t1.py
```

**步骤 5：去除空白切片（可选）**
```bash
python reg_series/kill_empty_slice.py
```

**步骤 6：图像配准**
```bash
python reg_series/preprocess.py
```
> 对每个患者的序列进行配准，确保器官和身体区域对齐

### 2. 模型训练

**步骤 1：配置训练参数**

编辑 `training_project/ce_mri_param.py` 文件，修改以下关键参数：

```python
# 常用参数
parser.add_argument('--Task_name', type=str, default='CE_MRI_simulate_PCa')  # 任务名称
parser.add_argument('--cuda_idx', type=int, default=0)  # GPU 设备编号
parser.add_argument('--fold_K', type=int, default=5)  # K 折交叉验证
parser.add_argument('--fold_idx', type=int, default=1)  # 当前折数

# 输入序列配置
parser.add_argument('--train_keys', type=list, default=["t1", "t2", "b50", "b800", "b1500", "adc"])

# 训练参数
parser.add_argument('--train_batch_size', type=int, default=8)
parser.add_argument('--num_epochs', type=int, default=500)
parser.add_argument('--lr', type=float, default=5e-5)

# 损失函数权重
parser.add_argument('--loss_weight_dict', type=dict, default={'vanilla_GAN_loss': 1, 'L1_loss': 20, 'SSIM_loss': 20})

# 数据路径（请根据实际路径修改）
parser.add_argument('--filepath_img', type=str, default='your_data_path')
parser.add_argument('--result_path', type=str, default='your_result_path')
```

**步骤 2：启动训练**

```bash
cd training_project
python train_main.py
```

## 模型架构

本项目采用 **Pix2PixHD** 架构，主要特点：

- **生成器（Generator）**：使用 RegNet 作为骨干网络，生成高质量的 CE-MRI 图像
- **判别器（Discriminator）**：采用多尺度判别器（Multi-scale Discriminator），增强生成图像的真实感
- **损失函数**：结合 GAN 损失、L1 损失、SSIM 损失等多种损失函数

### 支持的损失函数

| 损失函数 | 说明 |
|---------|------|
| GAN Loss | 对抗损失，使生成图像更真实 |
| L1 Loss | 像素级 L1 损失，保证图像内容一致性 |
| SSIM Loss | 结构相似度损失，保留结构信息 |
| MS-SSIM Loss | 多尺度结构相似度损失 |
| Perceptual Loss | 感知损失，基于预训练 VGG 网络 |
| Feature Matching Loss | 特征匹配损失 |

## 支持的 MRI 序列

本项目支持以下输入序列的组合：

- **T1**：T1 加权图像
- **T2**：T2 加权图像
- **b50**：DWI b=50 s/mm²
- **b800**：DWI b=800 s/mm²
- **b1500**：DWI b=1500 s/mm²
- **ADC**：表观扩散系数图

> 可通过修改 `train_keys` 参数自定义输入序列组合

---

## 评估指标

本项目提供以下评估指标：

- **PSNR**：峰值信噪比
- **SSIM**：结构相似度指数
- **MS-SSIM**：多尺度结构相似度
- **LPIPS**：学习感知图像块相似度

## 注意事项

1. **GPU 显存**：训练过程需要较大的 GPU 显存，建议显存 ≥ 12GB
2. **数据格式**：输入数据应为 NIfTI (.nii/.nii.gz) 格式
3. **预处理重要性**：数据预处理对最终效果影响很大，请严格按照流程执行
4. **路径配置**：运行前请确保所有数据路径已正确配置
